# Code Harmony

This is a private repository containing the code for [Code Harmony](http://codeharmony.dev). It is intended for internal development only.

## 🚀 Getting Started

## Project Setup

1. Install Git
    https://git-scm.com/
2. Adding a new SSH key to your GitHub account
    https://docs.github.com/en/authentication/connecting-to-github-with-ssh/adding-a-new-ssh-key-to-your-github-account
3. Clone repository on your machine using SSH
    repository SSH url : git@github.com:sahilkumar1012/code-harmony.git
4. Install Visual Studio Code
    https://code.visualstudio.com/
5. Open project in VSCode
6. Install node (for npm)
    https://nodejs.org/en/download/
7. Setup environment variable for node
    echo 'export PATH="/opt/homebrew/opt/node@22/bin:$PATH"' >> ~/.zshrc
8. Up this application on local
    npm start


Note: Follow contribution guidelines for modifications.


## 📢 Internal Use Only

1. Install the Firebase CLI
    npm install -g firebase-tools
2. Log in to Firebase
    firebase login
3. To Deploy
    npm run build
    firebase deploy

This repository is restricted to authorized developers.

Happy Coding! 🚀
